# Code of Conduct

Be decent, and assume good faith.

Fella is small and personal in spirit, and a good chunk of the people who show
up in issues and discussions aren't developers — that's the actual audience.
Treat them, and each other, accordingly.

## Not okay

- Harassment, personal attacks, or discriminatory language or jokes.
- Deliberately derailing an issue or discussion, or piling on someone over a
  design decision they didn't make.
- Publishing someone's private information without their consent.

## What happens if you don't

You'll be asked to stop. If it continues, you're removed from the project's
spaces (issues, discussions, pull requests) at the maintainer's discretion.

## Reporting

Open an issue if it's something you're comfortable discussing publicly.
Otherwise, use the contact info on the repository owner's GitHub profile.

This is the same standard `CONTRIBUTING.md`'s own "Conduct" section already
states; this file exists mainly so it's where people (and GitHub's own
community-health check) expect to find it.
