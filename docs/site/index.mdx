# An analytical workspace built around conversation

Fella is a local-first desktop app for working with your own information. Ask a question about a mounted folder, inspect the analysis behind the answer, and save useful results into a report.

## How the work is divided

| Part | Responsibility |
| --- | --- |
| Model | Interprets the request, chooses analysis steps, and composes an answer. |
| Rust harness and engine | Enforce workspace scope, run read-only analysis, record evidence, and perform deterministic checks. |
| JSON-render presentation | Composes a responsive view from registered components and saved result bindings. It cannot execute arbitrary model-authored code. |
| Investigation and report stores | Preserve questions, runs, findings, artifacts, revisions, and report snapshots locally. |

Fella can answer a general question without workspace evidence. For data-backed questions, open **How this was analyzed** in Chat or inspect the saved run in Notebook.

## Local files and model providers

The folder you choose is cataloged and analyzed locally. Fella does not give the model direct filesystem or database access. If you connect a hosted provider, prompts and requested file-derived results may be sent to it. Read [Privacy and security](/developer-platform/using-fella/privacy) before using sensitive information.
