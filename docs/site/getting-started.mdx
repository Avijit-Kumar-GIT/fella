## Start with one question

<Steps>
  <Step title="Install Fella">
    Download the latest published installer from [GitHub Releases](https://github.com/Avijit-Kumar-GIT/fella/releases/latest). This guide describes the v0.4.0 workspace; older installed versions may differ.
  </Step>
  <Step title="Connect a model provider">
    Open **Settings**, choose a provider, and add your own API key. Fella is BYOK-only. After connecting, the composer shows the selected model; choose a different available model there when needed.
  </Step>
  <Step title="Open a folder">
    Use the workspace switcher in the title bar to choose a folder. This folder is the explicit data boundary for file-backed analysis. Fella catalogs supported sources locally.
  </Step>
  <Step title="Review Files">
    Select **Files** in the left sidebar to browse the folder hierarchy, see which files were cataloged, and open supported previews. Check skipped files before relying on an answer.
  </Step>
  <Step title="Ask in Chat">
    Return to **Chat** and ask a specific question. For example: “Using orders.csv, compare net sales by month for 2024 and 2025, and explain the largest change.”
  </Step>
  <Step title="Inspect or preserve the work">
    Open **How this was analyzed** below a response for the run details. Open Notebook to create or review a persistent Investigation, or choose **Create report** to save a useful output.
  </Step>
</Steps>

## Supported inputs

| Kind | Formats | Current behavior |
| --- | --- | --- |
| Delimited tables | CSV, TSV, TAB | Loaded as queryable tables in the local analytics database. |
| JSON records | JSON, NDJSON, JSONL | Tabular objects become queryable tables. |
| Spreadsheets | XLSX, XLSM, XLSB, XLS | Usable sheets are loaded as separate tables; this is not a full workbook editor. |
| Text documents | TXT, TEXT, MD, MARKDOWN, LOG | Searchable and readable by analysis tools. |
| PDF documents | PDF | Text-layer extraction only; scanned pages need OCR elsewhere. |
| Parquet | PARQUET, PQ | Requires an optional DuckDB build and is not available in standard release installers. |

Fella does not edit, move, or delete source files. It does not currently provide DOCX or PPTX ingestion, OCR, or general-purpose previews for every file format. A table preview is a small sample, not a workbook viewer.

## What answers can contain

For data-backed questions, the model chooses analysis steps and then composes a view suited to the saved results. The JSON-render component catalog supports narrative, metrics, tables, charts, callouts, and presentation-only controls. Charts are not required for every answer; they are appropriate when they make a trend, comparison, ranking, distribution, or relationship easier to understand.

The answer remains useful if the model cannot produce a valid structured view: Fella keeps the canonical answer and the analysis details available. See [Ask questions](/developer-platform/using-fella/asking-questions) and [Reports](/developer-platform/using-fella/reports).

## A useful question pattern

State the measure, population, period, and comparison when they matter. You do not need to choose SQL, Python, or a chart:

> Compare net merchandise revenue for Q3 and Q4. Explain the metric, identify the largest category changes, and note any source limitations.

If the answer matters, inspect its source scope, computations, and verification checks. A successful query is not proof that its definition matched your intent.
