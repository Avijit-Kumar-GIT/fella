Select **Files** in the left sidebar to browse folders in the mounted workspace. The source list shows cataloged inputs and items Fella could not use. Open a supported source to inspect its profile or a small preview.

## Supported formats

| Kind | Extensions | What Fella does |
| --- | --- | --- |
| Delimited tables | CSV, TSV, TAB | Loads rows into the local analytics database. |
| JSON records | JSON, NDJSON, JSONL | Converts tabular records into queryable tables. |
| Spreadsheets | XLSX, XLSM, XLSB, XLS | Loads each usable sheet as a separate table. |
| Text documents | TXT, TEXT, MD, MARKDOWN, LOG | Makes text available to document search and reading. |
| PDF documents | PDF | Extracts selectable text; no OCR is performed. |
| Optional table format | PARQUET, PQ | Requires a custom build with the optional DuckDB feature. |

The Files view is not a general-purpose file manager. Fella does not edit or round-trip source documents. A tabular preview shows only a small sample, not the full spreadsheet.

## Catalog and source profiles

The catalog records table names, row counts, observed columns and types, basic field profiles, ingest notes, and skipped-file reasons. Use these details to catch issues such as missing values, mixed types, dropped preamble rows, or unexpected sheet names.

Catalog presence is not proof that a source covers the requested population, dates, or business definition. Check the run’s source scope and query as well.

## Documents

Document search reads cataloged text and returns matching passages. PDF support requires a text layer; scanned pages and photos need OCR elsewhere. Word and PowerPoint files are not supported inputs.

## Rescan after edits

When files change, refresh or reindex the workspace. Fella compares the catalog revision and can flag saved Questions or Findings that depend on older source state. Refreshing does not silently rewrite their results; review and explicitly rerun affected work.

<Note>
  The root fella.md file is context, not an evidence source. See [Context and memory](/developer-platform/using-fella/context-and-memory).
</Note>
