Workspace context helps Fella interpret your information. It does not prove a value, change source files, or grant the model new capabilities. Open **Workspace context** from the title-bar workspace actions, or use `/context`.

## The workspace guide

The root `fella.md` file is user-authored guidance for one mounted folder. Edit it in the Workspace context view or create it directly in the folder. It is included as context, not treated as an evidence source.

You might explain that amounts use GBP, transfers are not spending, or that one category should be grouped with another. Fella can use those conventions to interpret a question. Numbers in an answer still need evidence from the workspace.

## Knowledge learned from analysis

Fella can surface reusable facts while analyzing the workspace. Each fact keeps its origin, evidence references, source revision, authority, and current state. A proposed fact can remain provisional to its Investigation, be edited, be shared across the workspace, or be dismissed. Superseded facts remain available in the history. Review the provenance and freshness before relying on a learned fact.

## Investigation definitions and assumptions

An Investigation can store explicit definitions and assumptions for its own work. These are separate from folder-wide context and learned workspace facts. Each run records the exact definitions and revisions it received, so later edits do not rewrite its history. Definitions stay local to that Investigation unless the user explicitly promotes a fact to workspace scope.

Model-suggested meaning is not automatically authoritative. Review proposed definitions before relying on them in a later analysis or handoff.

## Existing folder memory

Earlier versions also saved lightweight vocabulary notes and reusable semantics as folder memory. This is not a cache of query results and should not replace source verification. Existing notes remain visible in Workspace context; use the memory controls to clear them when they no longer match your files.

## Context is not evidence or permission

| Information | What it can do | What it cannot do |
| --- | --- | --- |
| `fella.md` guide | Explain stable vocabulary, file conventions, or metric meaning. | Establish a numeric result without source evidence. |
| Learned workspace facts | Carry reviewed, provenance-linked facts at their accepted scope. | Make stale evidence current or grant file access. |
| Investigation definitions | Guide one Investigation and preserve revisions per run. | Rewrite the context of prior runs or silently become workspace rules. |
| Source data | Support an observed result when selected and analyzed. | Automatically establish that the selected population is complete. |

The Rust tool registry and engine enforce data access and execution boundaries. Context text cannot add a shell, write operation, network tool, or arbitrary renderer code.
