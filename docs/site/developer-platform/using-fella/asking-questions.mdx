Ask in Chat as you would ask an analyst who can inspect the mounted folder. Fella decides whether to inspect tables, search documents, use SQL, run sandboxed Python, or combine methods. You do not have to choose a tool.

## Ask for the decision you need

Include a measure, scope, and period when those details change the result:

> Compare net merchandise revenue by quarter for 2024 and 2025. Explain the largest changes and call out any data gaps.

For a direct lookup, a short question is enough. For a complex question, say what comparison or explanation would make the answer useful. If a metric has a formal definition, include it or point Fella to the relevant workspace context.

## What determines the answer layout

The canonical answer is grounded in the analysis. When the saved results support a useful structured view, Fella uses JSON-render to compose one from registered components: prose, metrics, cards, tables, charts, callouts, and limited presentation controls.

The model selects a composition based on the question and result shape. A time trend may use a line or area chart; a category ranking may use bars; exact records may work best as a table; a short explanation may need no chart at all. The catalog provides safe building blocks, not a single answer template.

Analytical values must bind to the supplied saved results. The presentation cannot execute arbitrary code or independently fetch data. If a view is invalid or unavailable, the answer and its analysis remain available in text.

## Continue the conversation or start an Investigation

Use a follow-up to clarify or narrow the current answer:

> Exclude canceled orders and show the result by product category.

Create an Investigation when you want a named objective, a Question plan, explicit source choices, run history, Findings, and coverage. Creating an Investigation opens its own linked conversation. A normal new conversation remains a chat and does not automatically create an Investigation.

## Review an answer

Open **How this was analyzed** to inspect the recorded run. Review the source files, filters, joins, definitions, returned values, and checks. For persistent Question coverage and saved Findings, open Notebook and select the Investigation.

General explanations can be answered without a data tool. Such a reply has no workspace evidence. File-specific claims and numbers should be supported by the recorded run.

## Stop, retry, or correct

Stop an active run with the stop control or Escape. The evidence gathered so far remains available. Use the retry action after a transient provider error. If the interpretation is wrong, state the correction in a follow-up or revise the Question and run it again.
