Conversations are saved locally and appear in the **Chat** section of the sidebar. A conversation can be an ordinary chat or the conversation linked to an Investigation.

## Sidebar organization

The sidebar has three destinations:

- **Chat** lists Investigations and other question conversations.
- **Files** browses the mounted folder and its catalog.
- **Reports** lists saved reports for the mounted folder.

The workspace switcher in the title bar selects the mounted folder. Selecting another folder changes the data context; it does not change the identity of the conversation or Investigation.

## Create and reopen

Use the plus button to start a conversation in the selected workspace. Use the Investigation actions menu to create a named Investigation; Fella creates a linked conversation for it. A normal conversation does not automatically become an Investigation.

Select a conversation to reopen its transcript. Use the sidebar search to find a conversation by its visible title or text. The model selected for each conversation remains associated with it.

Use Notebook to inspect the selected Investigation beside Chat in the same window. Notebook is a view over the saved Investigation; it does not create a second transcript or rerun analysis.

## Rename and delete

You can rename a conversation from its row. Deleting asks for confirmation and removes the transcript and its linked Investigation. Saved analytical outputs, reports, their revisions, and supporting analysis records remain in the workspace. The deletion dialog states what will be retained before you confirm.

Removing a workspace from the sidebar deletes its conversations but leaves the original folder and files untouched. Saved reports and results remain associated with that workspace and can be reopened after reconnecting the folder.

## Keyboard controls

| Shortcut | Action |
| --- | --- |
| Ctrl/Cmd+N | New conversation |
| Ctrl/Cmd+O | Open a folder |
| Ctrl/Cmd+K | Search |
| Ctrl/Cmd+B | Toggle the sidebar |
| Ctrl/Cmd+, | Open Settings |
| Ctrl/Cmd+Shift+A | New conversation |
| Enter | Send the message |
| Shift+Enter | Insert a new line |
| Escape | Stop an active run |

Use Command in place of Ctrl on macOS.
