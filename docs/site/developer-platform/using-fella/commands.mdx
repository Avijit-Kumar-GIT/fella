Most actions are available through the desktop interface. Type a slash in the composer to see command suggestions, or use the search shortcut to find an app action.

## Slash commands

| Command | Action |
| --- | --- |
| /open | Choose a folder |
| /files | List cataloged and skipped files |
| /schema name | Show a table’s columns and profile |
| /sql query | Run one read-only SELECT or WITH query |
| /login | Connect to or switch a model provider |
| /logout name | Stop using a provider; add forget to remove its saved key |
| /auth | Show provider connection status |
| /model | List or select a model |
| /reindex | Rescan the mounted folder |
| /memory | View or clear folder memory |
| /context | Open workspace context |
| /update | Check for an update |
| /mcp | Experimental and inert; no connectors are enabled |
| /new | Start a conversation |
| /plain | Toggle the plain view |
| /clear | Clear the current conversation |
| /history | List saved conversations |
| /retry | Retry the latest question |
| /help | Show the command reference |

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| Ctrl/Cmd+N | New conversation |
| Ctrl/Cmd+O | Open a folder |
| Ctrl/Cmd+K | Search |
| Ctrl/Cmd+B | Toggle the sidebar |
| Ctrl/Cmd+, | Open Settings |
| Ctrl/Cmd+Shift+A | New conversation |
| Enter | Send |
| Shift+Enter | Insert a new line |
| Escape | Stop the active run |

On macOS, use Command in place of Ctrl. Some system menu shortcuts depend on the operating system and desktop build.

<Note>
  Direct SQL is not an agent run. Its results do not receive an answer trace or post-answer verification. Use Chat when you need an answer tied to recorded evidence.
</Note>
