# Fella brand assets

- `fella-orb.svg` is the canonical scalable Fella mark.
- The root [`logo.svg`](../../logo.svg) is a convenient public copy for README,
  documentation, and other repository-facing surfaces.

The SVG is transparent and scales cleanly from a favicon to a large mark. Use
the application icon assets under `src-tauri/icons/` when a platform-specific
PNG, ICO, or ICNS file is required.
